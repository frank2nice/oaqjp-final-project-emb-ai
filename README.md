A Python-based emotion detection application using IBM Watson NLP that analyzes text and identifies emotions including anger, disgust, fear, joy, and sadness.

## Project Overview

This application uses the IBM Watson NLP Emotion Detection API to analyze text and determine the dominant emotion along with scores for each emotion. It provides both a command-line interface and a web-based user interface built with Flask.

## Features

-  **Emotion Detection**: Analyzes text for 5 emotions (anger, disgust, fear, joy, sadness)
-  **Dominant Emotion Identification**: Identifies the strongest emotion in the text
-  **Web Interface**: User-friendly web interface for easy interaction
-  **Unit Testing**: Comprehensive test suite for validation
-  **JSON Response**: Returns structured JSON data with emotion scores

## Technology Stack

- **Python 3.11**: Core programming language
- **IBM Watson NLP**: Emotion detection API
- **Flask**: Web framework
- **Requests**: HTTP client for API calls
- **PyLint**: Static code analysis
